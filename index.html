Quick answers

Need to know.

Use the web or Windows. Choose a Studio. Sign-in opens with billing.

Is the download the full product?

Yes for editing and preview. Local packs add captions, smoother motion, and generation. A plan unlocks clean export.

Web or Windows?

Use the web to start fast. Use Windows for larger projects.

Can I use my phone?

Yes. On the same Wi‑Fi, open the address shown in Studio to shoot reference photos from your phone.

What do reference captures do?

They record more angles of a person or product so edits stay consistent.

When do files upload?

Only when cloud processing is offered and you approve a job and its price.

What computer do I need?

Windows 10 or 11, 8 GB memory, and enough project storage.

Where is my usage?

When billing is live, Usage shows charges, refunds, credits, and balance.
